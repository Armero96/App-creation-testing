# CLAUDE.md — App-creation-testing

This repository holds small apps I build for my own use. **Each app lives in its own folder** (e.g. `Jobits/`), with its own `CLAUDE.md` describing that app. Read this file and the app's `CLAUDE.md` before starting any task.

---

## About me and how to work with me

- I'm **Jorge**, a scientist learning to code. I know some Python and I'm new to web development, JavaScript and app building.
- These projects are meant to teach me two things: **how apps are built**, and **how to give Claude clear instructions**.
- I use **Windows** and **VS Code**. This is a public Git repository on GitHub.

**Please:**
1. **Plan first.** Before writing code for a new feature, briefly describe what you'll do and which files you'll touch, and wait for my OK.
2. **Work in small steps.** Do one feature at a time, and stop after each one so I can test it.
3. **Explain in plain language.** After each change, tell me what you changed and why, in a few sentences. Add short comments to the code.
4. **Ask when something is unclear.** If the app's spec doesn't cover a situation (see its *Open questions*), ask me instead of guessing.
5. **Stay in scope.** Don't add features, libraries or tools that the app's `CLAUDE.md` doesn't ask for. Suggest them instead.
6. **Remind me to commit** after each working step, and suggest a short commit message.

## Repository layout and hosting

- The repository is published with **GitHub Pages** from the `main` branch, root folder. Each app is reachable at `https://armero96.github.io/App-creation-testing/<AppFolder>/`.
