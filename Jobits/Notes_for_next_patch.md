# Notes for next patch

1) I am missing a way to see things that were missed in the previous day, and thus prevented me to achieve the milestone. It goes a bit unseen, and thus, if I just ignore the app for long enough, nothing will happen.
2) It would also be nice if we were able to work on an incentive, other than just the progression of the character. Like a rewards screen, which is achieved every time either a day is completed, or a target exp. 
3) Swiping is not clear to the user on first sight. It should be clear that this is an option to access the entirity of the app
4) There is no way to immediately start using it. You need to figure out where to go first. A button like "add your first quest" on the main screen could help to get started for new users.
5) Colors and accents lead the users eye. On the right panel there are a lot of colors and buttons compete for your attention. This could be solved together with next point, if we just put a three dots menu, or more...
6) Don't put dangerous buttons next to useful buttons ("Reset everything" next to "+")
Assign screen real estate proportional to the use case. Export/Import are not used frequently and should somewhere else, not in the center of the screen.
7) Stick to clear wording. What is the difference between Standing and Repeating quests?
What does the right panel do? Is it a filter? If so, is this useful to have when there are no quests yet?
8) Adding a note or editing a note cannot be escaped using the back button. It goes to the previous page.
9) Button on the checklists does not respond when there is no text entered. That's confusing. One way to deal with that would be to gray the button out when there is no text entered.
